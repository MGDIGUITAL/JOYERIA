# Estilo C — Sketchnote / Journal

Estilo complementario. Estética de bullet journal / sketchnote profesional. Papel crema, caligrafía cursiva, cajas redondeadas, tinta negra con acentos de acuarela pastel. Para anuncios que se sienten personales, casi como una nota escrita por un amigo.

## Prompt template para Kie AI Nano Banana 2

```
A sketchnote-style illustration on cream-colored paper (light beige #FAF4E8).
The composition resembles a bullet journal page or hand-drawn note. Features:
{CONCEPT_DESCRIPTION}. Title in cursive calligraphy reading "{CURSIVE_TITLE}"
(in Spanish). Includes hand-drawn rounded boxes, arrows pointing between
elements, small bullet points or checkmarks, and decorative flourishes.
Black ink for outlines and lettering. Watercolor accents in pastel pinks,
butter yellow, soft sage green, and dusty teal. Composition feels like
a personal journal page with intentional but imperfect handwriting.
No human faces, no realistic avatars.
Aspect ratio: {RATIO}.
```

## Variables

- `{CONCEPT_DESCRIPTION}`: descripción del concepto + elementos visuales
- `{CURSIVE_TITLE}`: 2-5 palabras en español, en caligrafía cursiva
- `{RATIO}`: `1:1 square` / `4:5 portrait` / `9:16 vertical story`

## Conceptos visuales por ángulo de copy

### Dolor
- Página de journal con lista de TODOs todos tachados con frustración
- Mapa mental caótico con "yo" en el centro y muchas flechas saliendo a tareas
- Reloj con anotaciones alrededor: "8am — todavía nada", "2pm — sigo igual"
- Cursive title: "Otra vez igual" / "No alcanzo" / "El día se va"

### Aspiracional
- Página de journal con sistema visual: mapa con cajas conectadas funcionando
- Calendario semanal con todo en orden, anotaciones tipo "automático"
- Diagrama de "yo" + máquinas trabajando, todo conectado armoniosamente
- Cursive title: "Mi sistema" / "Por fin libre" / "Tiempo recuperado"

### "Te quedas atrás"
- Línea de tiempo con "antes / ahora / después" donde los que se mueven están adelante
- Mapa de evolución desde el martillo al smartphone al cerebro digital
- Bullet list con checkmarks: "los que aprendieron ✓", "los que esperaron ✗"
- Cursive title: "La ola es ahora" / "El que no se mueve" / "Decide ya"

## Reglas

- **Fondo**: papel crema `#FAF4E8`. NUNCA blanco puro ni beige oscuro.
- **Líneas**: tinta negra principal + acentos acuarela. La tinta debe verse "de verdad" no digital.
- **Caligrafía**: el título cursivo es central. Imperfecto pero legible.
- **Composición**: tipo notebook page. Cajas, flechas, bullets. Pero NO sobrecargada.
- **Color**: pastel sutil. Nunca saturado. La tinta negra es la protagonista.
- **Imperfección**: la "imperfección journal" es parte de la magia.
