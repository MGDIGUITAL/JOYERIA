# Tono de copy — Horizontes IA

Voz de Santi para anuncios de Meta. Español LATAM natural, casual, anti-jerga. Como le hablarías a un amigo en una mensaje de WhatsApp, no como una agencia escribiendo para "su cliente".

## Principios

1. **Segunda persona singular ("tú")**, NUNCA "usted" ni "ustedes"
2. **Frases cortas**. Si una frase tiene más de 15 palabras, partir
3. **Cero jerga marketing**: prohibido `embudo`, `funnel`, `optimizar`, `escalar`, `monetizar`, `growth hack`, `ROI`, `lookalike`, `A/B test`
4. **Cero clichés tech**: prohibido `disruptivo`, `revolucionario`, `cambio de paradigma`, `nivel pro`, `desbloquea tu potencial`
5. **Concreto sobre abstracto**: "ahorra 3 horas a la semana" beats "aumenta tu productividad"
6. **Honesto sobre exagerado**: si algo cuesta esfuerzo, decirlo. La gente desconfía de las promesas perfectas
7. **Máximo 1 emoji por anuncio**. Y solo si aporta. Cero strings de emojis decorativos

## Estructura por ángulo

### Versión 1 — Dolor

**Patrón**:
- Línea 1: el problema, en voz de la persona ("¿No te pasa que…?")
- Línea 2: empatía + reformular el dolor
- Línea 3: insinuación de la solución (sin venderla todavía)
- CTA: invitación suave

**Ejemplo (curso de automatización)**:
```
Título: "El día se te va en lo mismo"
Texto principal: ¿Tareas repetitivas otra vez? Reportes, mensajes, follow-ups. Sabes que se pueden automatizar pero nunca encuentras cómo. Mira lo que está pasando con IA.
Botón: Saber más
```

### Versión 2 — Aspiracional

**Patrón**:
- Línea 1: el escenario ideal, concreto y visual
- Línea 2: lo que la persona sentiría / haría con ese tiempo libre
- Línea 3: prueba específica (caso, número, anécdota)
- CTA: invitación a entrar al sistema

**Ejemplo**:
```
Título: "Tu negocio funcionando solo"
Texto principal: Imagina lunes 9am. El reporte semanal en tu bandeja, los leads contactados, las redes publicadas. Todo solo. Hay personas que ya viven así. Te enseño cómo.
Botón: Empezar
```

### Versión 3 — "Te quedas atrás"

**Patrón**:
- Línea 1: contexto del cambio (sin ser dramático, factual)
- Línea 2: división entre los que se están moviendo y los que no
- Línea 3: invitación a no ser el segundo grupo
- CTA: directo

**Ejemplo**:
```
Título: "El IA ya no es opcional"
Texto principal: La gente que está usando IA bien está sacando 5x más en menos tiempo. La que no, está pagando lo mismo y tardando el doble. ¿De qué lado vas a estar en 6 meses?
Botón: Empezar ahora
```

## Reglas de longitud

- **Título** (Headline): máx 40 caracteres. Idealmente 5-7 palabras.
- **Texto principal** (Primary text): máx 125 caracteres antes del "see more". Total máx 200.
- **Botón** (CTA): de la lista permitida de Meta (Saber más / Registrarme / Empezar / Comprar / Reservar / Suscribirse).

## Palabras a evitar (lista negra)

| ❌ NO usar | ✅ Usar en su lugar |
|---|---|
| Funnel, embudo | el camino / proceso |
| Optimizar | hacer mejor |
| Escalar | crecer |
| Monetizar | cobrar / vender |
| Disruptivo | nuevo |
| Revolucionario | (omitir, el lector lo decide) |
| Game changer | (omitir) |
| Nivel pro | bien hecho |
| Desbloquear | empezar a |
| Roadmap | plan |
| Stack | herramientas |
| ROI | ganancia / retorno |
| Crispar | (omitir) |
| Conversiones | personas que compran |

## Palabras OK (pero con cuidado)

- "Tiempo" (concreto: cuánto)
- "Sistema" (si está claro qué hace)
- "Automatizar" (es claro, OK)
- "Herramientas" (mejor que "stack")
- "IA" (no "inteligencia artificial" salvo que el contexto lo pida)
- "Skill" (si la audiencia es tech-aware)

## Tono físico

Si el copy lo leyeras en voz alta, debería sonar como Santi hablando en un short de Instagram. No como un narrador corporativo. Si suena a "agencia de marketing escribiendo", está mal y se reescribe.
